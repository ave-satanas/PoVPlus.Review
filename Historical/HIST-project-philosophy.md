# Project philosophy and intervention framework

From `ARCH-002-Project-philosophy`, `DEV-004-Intervention-framework`, `DEC-004-Project-governance`, adopted 2026-10-24. `[decision]` at that time. Not reconfirmed since, so check before treating as binding, though recent work follows it.

**Identity:** PoVPlus is a personal Valheim compatibility, integration and customization framework, shaped around the user's gameplay preferences. It does not aim to recreate a modpack.

**Principles:** "Preserve what works. Improve what falls short. Replace what fundamentally fails." "Minimum unnecessary duplication, maximum intentional design."

**Priorities:**
1. Resolve genuine compatibility problems.
2. Modify features to match preferences and design.
3. Integrate disconnected systems.
4. Correct defective or redundant mechanics.
5. Add original functionality when existing solutions fall short.

A preference does not need a proven upstream bug, but must be described honestly: an intentional upstream design can work correctly and still not suit this project.

**Classify work as:** verified technical defect, verified compatibility conflict, design disagreement or preference, missing integration, missing feature, redundant system, or unresolved hypothesis. Overlapping settings, patches or features do not establish a conflict. An optional probe can explain an unavailable integration.

**Approaches:** configure, integrate, patch, extend, replace, remove. These are options, not an escalation ladder. Replacement needs a concrete benefit and a defined transition.

**Boundaries:** keep mod-author adaptations unless a specific decision changes them. Path of Valheim progression and balance remain the baseline for assessing effects.
