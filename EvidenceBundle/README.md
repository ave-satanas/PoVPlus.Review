# Sanitized evidence snapshot

**This is a sanitized snapshot, not raw evidence.** It supports the records in this repository. It does not replace observations you can reproduce yourself.

Everything except this README is generated by `tools/make_evidence_bundle.py`. Do not edit those files here.

## Provenance

`MANIFEST.tsv` has one row per file:

| Column | Meaning |
|---|---|
| `source_id` | Path of the original in the original workspace |
| `source_sha256` | Full hash of the original, as it existed |
| `bundle_path` | The file here |
| `bundle_sha256` | Full hash of the file here |
| `transformation` | Line filter, redaction, banner, or none needed |
| `original_available` | Whether a reviewer can get the original |

The two hashes differ by design, unless no change was needed.

**A hash of an original you cannot obtain does not let you verify its contents.** It only lets the holder of the original show later that a file is the same one. You can verify `bundle_sha256`, which proves the file here is the one recorded, not that what it says is true. The owner wrote the manifest, so it is not independent evidence.

## Checks

From the repository root:

```
python tools/make_evidence_bundle.py --verify
```

This needs nothing else. It checks bundled hashes, lists anything unlisted, and scans for a few forbidden patterns.

`--check` also compares the bundle with the originals when they are present, as on the original machine, and exits with an error if anything is stale. Elsewhere it says the originals were not checked. `tools/validate.py` runs the same checks.

Regenerating overwrites the bundle, so changes must be reviewed first. It needs the original workspace and a local file of private terms that is not in this repository.

## Not included

Raw logs, saves, screenshots, per-object census data, wave CSVs, game files, third-party mods and their shipped data.

## Tested DLL

`release/PoVPlus.Compat.dll` and the zip are exact bytes, so their two hashes match. This is the project's own MIT-licensed code. The DLL has no embedded resources, and defines types only in its own namespace. It references other mods at runtime and bundles none of them, and it needs them to do anything. Its only embedded path is a build path on the original machine.

Do not install it unless your own user asks you to. Having the DLL proves which bytes were tested, not what they do.

## Frozen configuration

`config-1.0.1/` was taken once, from the live client profile, after the 1.0.1 acceptance run, with no included file changed since that run ended. **It is never regenerated**, because live config files change on every game launch. `--check` verifies it against `CONFIG-MANIFEST.tsv` only. All 274 files still matched the live client after the Gale profile acceptance run.

- **Included:** 274 `.cfg`, `.yml`, `.yaml`, `.json` and `.txt` files, 6 of them redacted.
- **Excluded, 295 files:** player identity and state files, caches, generated reference files, logs, backups, translations, media, and data shipped by mods, such as EpicLoot's `baseconfig`. `configstate.json` records hashes for that EpicLoot data.
- **Limits:** this is the client side. The server instance differs in the files listed in the reconciliation record, and in BetterSleepBruh test mode during some runs. Many values are mod defaults, not choices. Config files were not diffed against defaults, because defaults were not captured.

## Sanitization

Steam IDs, character and player names, user-home paths, the Steam library path and a disposable server password are replaced with placeholders such as `<real-character-1>`. Filtered files keep only lines matching a recorded pattern, so they omit context. A filter can hide things, and the patterns are in `tools/make_evidence_bundle.py`.

This is pattern-based and can miss things.
