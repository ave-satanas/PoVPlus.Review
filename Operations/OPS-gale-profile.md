# Gale profile

Gale 1.23.3, profile `PoVPlus`. Evidence: M37.

## What "outdated" meant

The installed mods were not out of date against the tested pack. The records about them were.

| Item | Before | After |
|---|---|---|
| Gale package records | 87, no PoVPlus.Compat | 88, PoVPlus.Compat 1.0.1 as a local import |
| PoVPlus.Compat folder | `plugins\PoVPlus.Compat`, unknown to Gale | `plugins\PoVPlus_Compat`, Gale-owned |
| `PoVPlus.txt` | Stale: 25 versions, PlanBuild, one malformed line | Regenerated by Gale: 87 packages, no PlanBuild, no malformed line. Local imports are not listed |
| Installed DLLs, other mods | 86 packages matched their Gale versions | Unchanged |
| Config | Tested state | Unchanged. All 274 frozen files match |
| Modpack metadata | Version 1.5.5, old changelog | **Unchanged**, see below |

PlanBuild was already absent. No duplicate packages, disabled files or superseded standalones remained. The pre-change backup is `backups\gale-pre-compat-import\`; it holds Gale's whole database, including its login table, so it must stay local.

## Upstream updates not taken

Gale offers three. All are ticked by default in its update dialog, so **do not use Update all** while these stand.

| Package | Pack | Offered | Why not taken |
|---|---|---|---|
| EpicLoot | 0.15.4 | 0.15.6 | Would hit the ItemDataStack IL guard. Needs [[OPS-revalidation]] |
| MyDirtyHoe | 2.3.3 | 2.3.4 | Not tested with the pack |
| CreatureManager | 1.3.10 | 1.3.11 | Not tested with the pack |

The dialog was cancelled. Gale's ignore list is empty. These updates may be worthwhile; they were not examined.

## Unresolved ambiguity

Gale's modpack metadata still says 1.5.5. That snapshot had 90 packages: it included PlanBuild, OdinPlus-BeeQueen and sighsorry-VeiledRecipes, and differed in 29 versions. No newer pack version was ever assigned, so the intended number for this pack is `[unknown]`. It matters only when publishing. The user decides it.

Do not bundle `Build-PoVPlusRelease-v3.ps1` in any pack: it contains the server address.

## Verification limits

70 DLLs are byte-identical to Gale's cached packages. 15 packages have no cache copy, so their bytes were checked only against the server and allow-list, not against a source: Riverheim, Expand_World_Prefabs, RegenWhileSitting, JsonDotNET, MissingPieces, ConditionalConfigSync, GammaOfNightLights, HelheimHarmonizer, BowsBeforeHoes, Server_devcommands, Venture_Logout_Tweaks, Venture_Floating_Items, Comfortable, Muted_Mist, PoV_Link. BepInExPack sits in the profile core.

Gale's database was read from a copy. Its `auth` table was not read.

## Client and server differences

Intended: the server also holds the four BakaLoader tools in [[CURRENT-STATE]], so it loads 90 plugins to the client's 86. Other DLLs match by hash, and the seven protected config files match. Full table: `pack-inventory.tsv` in the bundle's `results/`.
